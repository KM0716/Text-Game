# 代号：ZDay

一款基于 AI 的末日生存文字冒险游戏。角色设定、世界沙盒、战斗与探索，所有决策都将影响你的生存。

## 功能特性

- **角色创建**：自定义姓名、性别、年龄、外貌、技能、特质、背景故事
- **世界沙盒**：12 种预设世界模板（丧尸、真菌灾变、核战废土、AI 叛乱等）
- **实时叙事**：由 AI 驱动的剧情生成，每一步选择都会影响故事走向
- **物品系统**：背包、装备、合成、使用效果全链路实现
- **战斗系统**：回合制战斗、状态效果、Boss 战
- **线索系统**：可拖拽的线索便签板，剧情推进时自动更新
- **天气/季节**：昼夜循环、天气变化、季节更替
- **BGM 系统**：36 首背景音乐，按场景/情绪自动切换
- **音效系统**：丰富的拾取/装备/搜索音效，独立播放不被 BGM 覆盖
- **存档系统**：本地自动存档 + 10 个普通槽位 + 1 个可视化 AUTO 槽
- **图鉴系统**：NPC 幸存者图鉴，按势力分类展示关系、背景、特征标签
- **成就系统**：58 个成就（战斗/生存/探索/社交/隐藏）
- **突发事件**：27 个随机事件 + 10 个事件触发器
- **势力系统**：8 大 NPC 势力（军方/医疗/工程师/商人/学生/匪徒/独行/隐藏），AI 可区分归类
- **物品引用**：输入栏支持物品芯片（加粗整体样式），防止误删
- **API 配置**：支持 OpenAI / DeepSeek / Ollama 等多种服务商
- **代理模式**：支持通过代理服务器转发 API 请求，解决 CORS 跨域限制
- **移动端适配**：响应式布局，手机/平板/PC 均可游玩，触摸优化

## API 配置

首次进入游戏时需要配置 AI 服务商：

1. **服务商预设**：选择 OpenAI / DeepSeek / Ollama
2. **端点地址**：通常自动填充，也可手动输入
3. **模型**：选择或输入模型名（如 `gpt-4o`、`deepseek-chat`）
4. **API 密钥**：粘贴你的 API Key

**代理模式**（可选）：

- 如果在 GitHub Pages 等静态站点环境遇到 CORS 跨域问题，可以在设置中开启代理模式
- 需要填写代理服务器地址和密钥
- 代理配置会自动保存到浏览器本地存储

**API 配置持久化**：

- 配置完成后自动保存至浏览器 `localStorage`
- 刷新/重开页面后自动读取，无需重复输入
- 清除浏览器数据会丢失配置，建议使用"导出存档"功能备份
- 多浏览器/多设备需要分别配置

## 存档说明

- 每次 AI 回复后会自动存档到 **AUTO 槽**（可视化显示在存档面板最上方）
- **10 个普通存档槽** + **1 个 AUTO 自动存档槽**
- AUTO 槽可手动点击"立即存档"更新，也可随时"读取"恢复
- 所有存档保存在浏览器 `localStorage`（约 5MB 限制）
- 数据包含：角色状态、位置、线索、装备、对话历史、沙盒设置、NPC 关系
- **配额保护**：历史对话自动裁剪，超过阈值时自动清理备份
- **备份机制**：关键数据均有 `_bak` 副本，损坏时自动恢复
- **导出/导入**：设置面板可导出/导入完整存档（JSON 格式）
- 清除浏览器数据会丢失存档，请定期使用导出功能备份

## 图鉴系统说明

图鉴（📖 按钮）收录所有已邂逅的 NPC 幸存者，按**势力分类**展示：

- **势力标签**：军方/医疗/工程师/商人/学生/匪徒/独行/隐藏
- **AI 可理解模板**：每个 NPC 包含 `faction`、`personality`、`occupation`、`backstory`、`notes`（特征标签数组）、`dialogue`（分层对话）、`gifts`（礼物偏好）等字段，供 AI 对话时区分、归类和调用
- **信任分级**：敌对（<20）→ 冷淡（20-39）→ 普通（40-59）→ 友好（60-79）→ 亲密（≥80）
- **势力筛选**：点击顶栏筛选按钮可按势力过滤 NPC

## 成就与突发事件

- **成就系统**：在顶栏"成就"按钮查看当前进度。分类：
  - 战斗成就（击杀数/武器使用）
  - 生存成就（存活天数/无伤通关）
  - 收集/制造成就
  - 探索成就
  - 社交成就
  - 特殊/隐藏成就
- **突发事件**：游戏进行中随机触发，分为：
  - 危险类（袭击/陷阱）
  - 生存类（空投/补给）
  - 社交类（遭遇 NPC/势力冲突）
  - 发现类（隐藏储藏/线索）
  - 信息类（广播/谣言）

## 输入栏物品引用

输入栏支持 `contenteditable` 富文本输入：

- 输入 `物品名` 或从背包点击物品后，会自动转换为**芯片样式**（加粗整体、黄棕色边框）
- 芯片为整体元素，删除时需整段删除，防止误删字符导致 AI 无法识别
- AI 接收到的行动文本会解析芯片为实际物品名进行查询

## 常见问题

**Q: 页面加载很慢？**
A: BGM 文件较大（约 270MB），首次访问需要下载。建议使用 Chrome/Edge 并启用缓存。

**Q: API 配置能保存吗？**
A: 能。配置保存后自动跳过欢迎弹窗，刷新后直接进入游戏。

**Q: 存档会丢吗？**
A: 清除浏览器数据会丢失。建议定期通过设置面板导出存档 JSON 文件备份。

**Q: 手机能玩吗？**
A: 可以。游戏已适配移动端（响应式布局 + 触摸优化 + 移动端属性栏/图鉴适配）。

**Q: BGM 不播放？**
A: 浏览器要求首次交互后才能播放音频。点击页面任意位置即可启动。

**Q: 点击音效有时不响？**
A: 已修复。音效播放已改为独立音频实例，不再被 BGM 覆盖，也不会因缓存导致间歇性失效。

**Q: 装备卸下后看不到变化？**
A: 已修复。卸下装备后界面会立即刷新，无需关闭重开装备面板。

**Q: 遇到 CORS 跨域错误怎么办？**
A: 在设置面板的"网络代理"部分开启代理模式，或自行部署一个代理服务器转发 API 请求。
